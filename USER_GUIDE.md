# User Guide

Plain-language guide to running the demo and retraining each model. For the full
technical breakdown (why each step exists, what's already done, what's still missing on
a fresh machine), see `RUN_ORDER.md`. Before doing anything below, run
`python check_setup.py` once to see what's already on your machine and what's missing.

All commands below assume you already ran `pip install -r requirements.txt` from the
project root.

## How to Run - Run the Doctor Recognition Model

1. Open a terminal and go into the `app` folder: `cd app`
2. Start the demo: `streamlit run streamlit_app.py`
3. Your browser should open automatically. If not, copy the `http://localhost:8501`
   link the terminal prints and open it yourself.
4. Upload a handwritten word image, pick a model, and see the result.

## How to Train - Train Normal Handwriting of CRNN from zero

1. Make sure `iam_words.zip` and `words_new.txt` are placed at
   `data/normal/I_Am_Dataset/`, and CRNN's own split files
   (`data/normal/crnn/train.csv`, `val.csv`, `test.csv`) already exist. These split
   files cannot be regenerated by any script here, so they must be handed to you
   directly - see `DATA_PROVENANCE.md`.
2. `cd train_model/normal/crnn`, then run `train_iam_only.py` - path
   `train_model/normal/crnn/train_iam_only.py`. This trains CRNN from scratch on IAM
   and saves the checkpoint under `checkpoint/normal/crnn/`.
3. Still in the same folder, run `test_CrnnNormal.py` - path
   `train_model/normal/crnn/test_CrnnNormal.py`. This checks how well the checkpoint
   from step 2 performs on IAM's held-out test words.

## How to Train - Train Normal Handwriting of TrOCR from zero

1. `cd preprocessing/normal`, then run `generate_trocr_split.py` - path
   `preprocessing/normal/generate_trocr_split.py`. This builds TrOCR's own IAM 95/5
   split straight from `words_new.txt`. Skip this step if
   `data/normal/trocr/train.csv` and `val.csv` already exist.
2. `cd train_model/normal/trocr`, then run `finetune_TrOCR.py` - path
   `train_model/normal/trocr/finetune_TrOCR.py`. This downloads
   `microsoft/trocr-base-handwritten` from Hugging Face the first time (needs internet)
   and fine-tunes it on IAM. Saves the checkpoint under `checkpoint/normal/trocr/`.
   This is the slowest step in the whole guide - expect it to take a while.
3. Still in the same folder, run `test_TrOCR.py` - path
   `train_model/normal/trocr/test_TrOCR.py`. Checks the checkpoint from step 2 against
   IAM's validation words.

## How to Train - Train Doctor Handwriting of CRNN and TrOCR

1. `cd preprocessing/doctor`, then run `combineDataset.py` - path
   `preprocessing/doctor/combineDataset.py`. Merges the 3 raw prescription datasets
   into one folder, `data/doctor/doctor_raw/`.
2. Still in the same folder, run `discover_doctor_duplicates.py` - path
   `preprocessing/doctor/discover_doctor_duplicates.py`. Finds images that appear more
   than once in the combined dataset.
3. Run `resolve_doctor_duplicates.py` - path
   `preprocessing/doctor/resolve_doctor_duplicates.py`. Removes the duplicates found
   in step 2 and writes the cleaned dataset to `data/doctor/doctor_clean/`.
4. Run `split_doctor_clean.py` - path
   `preprocessing/doctor/split_doctor_clean.py`. Splits the cleaned dataset into
   train/validation/test (70/10/20).
5. Run `validate_doctor_clean.py` - path
   `preprocessing/doctor/validate_doctor_clean.py`. Double-checks that nothing went
   wrong in steps 1 to 4.
6. `cd train_model/doctor`, then run `generate_doctor_preprocessed.py` - path
   `train_model/doctor/generate_doctor_preprocessed.py`. Applies all four candidate
   preprocessing methods (baseline, clhaa, fajardo, benitez) to the images and saves
   the results, so the training steps below don't have to redo this work each time.
7. Run `pilot_compare.py` - path `train_model/doctor/pilot_compare.py`. Quickly
   fine-tunes both models on a small 15% slice of the data, for every preprocessing
   method, just to see which methods are worth fully training.
8. Run `finetune_all.py` - path `train_model/doctor/finetune_all.py`. The real,
   full fine-tune of CRNN and TrOCR on the winning preprocessing method(s). This
   produces the actual checkpoints under `checkpoint/doctor/crnn/` and
   `checkpoint/doctor/trocr/`, and is the biggest training step in this guide.
9. Run `final_test_eval.py` - path `train_model/doctor/final_test_eval.py`. Scores
   the finished checkpoints from step 8 on the held-out test set. This produces the
   final numbers you'd actually report.

## Special cases: pausing, resuming, and re-running

- **If training gets interrupted (crash, closed terminal, power loss), just run the
  exact same command again.** You do not need to pass any special flag or edit any
  code.
  - CRNN scripts automatically look for the latest `last*.ckpt` file and pick up
    training from there.
  - TrOCR scripts automatically look for the latest `checkpoint-*` folder and pick up
    training from there.
- **`pilot_compare.py` and `finetune_all.py` skip a preprocessing method entirely if
  it already has a `DONE.txt` file in its checkpoint folder** - meaning that method
  already finished training in a previous run, so nothing happens if you run the
  script again; it just moves on to whatever is still incomplete.
- If you are setting this project up on a brand-new machine with nothing pre-downloaded,
  read `RUN_ORDER.md` first - it explains exactly which raw files need to be handed to
  you before any of the steps above will work.
